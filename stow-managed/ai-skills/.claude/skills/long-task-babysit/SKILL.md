# 长任务托管

## 起任务

- 远程/本机长任务不要前台裸跑:`nohup … > /path/log 2>&1 &` 或
  `systemd-run --user --unit=<name> …`(能用 systemd 就用,方便查状态和自动重启)
- 日志必须落文件,路径当场告诉用户
- 能拆分并行的先拆(按模块/按数据分片),不要串行干等

## 盯任务

- 定时检查:进程活着没、日志尾部有没有报错、产出是否在增长
- 可预期的失败(OOM、网络闪断、依赖临时挂)直接修复后续跑,不要停下来等人
- 修不了的失败:保留现场(日志尾部 + 复现命令),汇报后再等指示

## 进度汇报格式(被问"啥进度了"时)

一句话说清:**阶段/百分比 + ETA + 最近一条关键日志**。
例:「3/5 个模块编译完,预计还要 20 分钟,当前在 link libfoo」。
不要只回"还在跑"。

## 收尾

任务结束(成功或失败)主动汇报:结果、产物路径、日志路径、下一步建议。
